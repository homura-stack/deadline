# キャラクター素材

## 正式Pico

ゲームで使用する`pico-final.png`は提供された正式な透過PNGです。再生成・切り抜き・リサイズ・色変更せず導入しています。

- 寸法：1295 × 1214 / RGBA
- SHA-256：`df2d8295764d489b79b41bd079e5b554f7f601138bdbc4bd436923ae059d3faf`
- 戦闘表示幅：48、高さ約45.0。anchor：.56 / .47
- プレイヤー判定半径：9。羽・触角の端まで判定を広げません。
- 通常戦闘、TRAINING、EXECUTE、被弾、LIGHT RESTORED、WORLD MAPで同じ正式素材を使用します。

## 敵素材と表示

敵3画像は提供された集合画像を画像編集ツールで個別に背景除去・透過化したPNGです。新しいキャラクター案ではありませんが、元画像と画素単位で同一の切り抜きではありません。制作時の集合画像のSHA-256は`3c3453770419c20dd90cd2afed8c3527dfeaf01689f1f25c416c8d48a9ba3c51`です。

現行値は[character-assets.js](../../character-assets.js)で管理します。

| 素材 | 内容 | 原寸 | 表示幅 | anchor x / y |
| --- | --- | --- | --- | --- |
| `enemy-01.png` | 赤コア・球体・棘 | 1254 × 1254 | 52 | .499 / .478 |
| `enemy-02.png` | シアンコア・三角形 | 1536 × 1024 | 52 | .5 / .555 |
| `enemy-03.png` | 紫コア・四枚の羽 | 1254 × 1254 | 50 | .504 / .482 |

表示高さは縦横比から算出し、発光コアをゲーム座標へ合わせます。敵の判定半径は15です。ENEMY 02はTARGETのシアンと区別するため、表示キャッシュ上だけ色相を変更します。原本PNGは変更しません。

| 攻撃タイプ | 素材 |
| --- | --- |
| AIM / FAN | ENEMY 02 |
| BURST | ENEMY 01 |
| ROTATE / 予備実装DELAY | ENEMY 03 |

攻撃タイプの色・識別表示は描画側で加えます。DELAYは通常のWave構成には追加していません。

4画像を通常表示・ヒット発光用の小さなCanvasへキャッシュします。PNGのalphaと縦横比を保持し、読み込み中・失敗時は既存図形へフォールバックします。素材読み込みのために戦闘時間を停止する処理はありません。外部画像サービスや画像加工ライブラリは配信ページから使用しません。
